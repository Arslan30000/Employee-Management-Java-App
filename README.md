# CoreSync Employee Payroll & Leave Management System - Client

A secure and user-friendly Java desktop application designed to streamline HR operations by automating employee onboarding, leave tracking, and payroll calculations.This repository contains the frontend client built exclusively with Java.

* **UI Framework:** Java FX
* **Networking:** `java.net.http.HttpClient` for REST API consumption
